## Project

CLIMA ATHENS PRO is a static Greek landing page. Business facts, prices, and the phone number live only in `lib/site.ts`. Do not add reviews, ratings, years of experience, or prices that are not already there.

- Dev server: `npm run dev -- --hostname 0.0.0.0 --port 3000`
- Lint: `npm run lint`
- Production build: `npm run build`

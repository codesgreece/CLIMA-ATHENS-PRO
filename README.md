# CLIMA ATHENS PRO

Mobile-first landing page for CLIMA ATHENS PRO, a refrigeration and air-conditioning service covering Attica and Salamina.

## Run

```bash
npm ci
npm run dev
```

The dev server listens on [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

## Content

Business copy, prices, the phone number, and the canonical URL placeholder live in `lib/site.ts`. The canonical origin is `https://clima-athens-pro.example` until the production domain is set.
